# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/). Until 1.0, minor versions may include breaking changes.

## [Unreleased]

### Documentation

- English README, documentation set under `docs/` (architecture, self-hosting, configuration, development,
  integrations, feature reference, glossary) and English design system in `DESIGN.md`.
- Contributing guide, security policy, issue and pull request templates.
- Continuous integration: types, tests and web build on every push and pull request.

## [0.1.0] - 2026-11-17

First open-source release under the AGPL-3.0.

- Story desk: claim-by-claim checking against a dossier, reporting decisions, publication checklist and sign-off,
  second opinion, style guide, audit view.
- Legal shield: right-of-reply requests, Wayback captures, text versions, defense package with RFC 3161 timestamps,
  sheet for the lawyer, public sources page.
- Documents and recordings: Ask the document, quote checks against interview transcripts, in-app recorder.
- Living stories: source-change alerts, update and correction posts, court-case tracking (DataJud), FOI requests
  (Brazil's LAI).
- Newsroom pipeline and distribution: monitored sources, triage, leads, validated pieces, carousels, Reels, Instagram
  publishing, publication certificates.
- Self-hosted mode (`INSTALACAO_PROPRIA=1`) with per-outlet AI keys.
