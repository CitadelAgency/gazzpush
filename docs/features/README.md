## Principles that apply everywhere

- **The model points, code verifies.** Any passage a model cites is checked letter by letter against the stored
  source before it counts.
- **Nothing is rewritten for the journalist.** Checks flag; people decide. Every decision is recorded with who and when.
- **Never silent.** A model that is down, refuses or answers out of format leaves a visible "not checked" state with
  the reason, never a missing result.
- **Brazil-specific parts are marked.** FOI requests, court tracking and news triage implement Brazilian law and data;
  the rest is language- and country-neutral.
